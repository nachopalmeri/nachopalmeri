## Con presión real antes de programar

Antes de tocar código manejé caja, inventario y auditorías en atención al cliente. Esa presión operativa — plata que tiene que cuadrar, stock que tiene que estar, procesos que no pueden fallar — es la que meto en cada herramienta que construyo. No hago ejercicios de curso: hago software que gente real usa para resolver un problema real.
